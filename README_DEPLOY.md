# Play At Scale finance-program replacement files

Replace/add these files in the existing Play At Scale repository root:

- `education.html` replaces the current education page.
- `resources.html` replaces the current resources page.
- `education-program.css` is new and is referenced by the replacement `education.html` after the existing `styles.css`.

The package intentionally does not replace global `styles.css`, `site-data.js`, `script.js`, brand assets, or unrelated pages.

Canonical public program facts in this release:

- Finance & Strategy Overview seminar: 1 hour, $50.
- Business Finance Foundations: 2.5 hours, $250.
- Financial Management & Analytics: 2.5 hours, $250.
- Strategic Finance & Capital Allocation: 2.5 hours, $250.
- Complete three-level applied program: $500 for all three applied levels.
- Standalone levels total $750, so the package price is $250 less.
- The one-hour seminar is separate from the $500 applied-level package and does not substitute for an applied level in the professional certificate pathway.
- Do not describe the complete program as a one-day bundle.
