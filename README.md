# Play At Scale Website v2

A production-ready static website for GitHub Pages.

## Public pages

- `index.html` - home
- `advisory.html` - advisory services
- `education.html` - CannaCon / business education program
- `resources.html` - downloads, webcasts, and Vimeo on-demand content
- `about.html` - Lucas Hobbs / firm background
- `contact.html` - schedule and email
- `privacy.html` - privacy notice

## Shared site files

- `styles.css` - all site styling
- `script.js` - navigation and dynamic content rendering
- `site-data.js` - changeable links, payments, downloads, photos, testimonials, webcasts, and Vimeo IDs

## Most future updates

Start with `CONTENT-GUIDE.md`.

The site is designed so recurring content changes generally require editing `site-data.js` and adding/replacing files in `assets/`, rather than rewriting HTML pages.

## GitHub Pages

Keep the existing repository `CNAME` file. This package intentionally does not include one.
