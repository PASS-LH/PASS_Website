Accessibility & accommodations

CannaCon should be usable by everyone.

We design the website toward WCAG 2.2 AA and work with venues to support reasonable event accommodations.

Website accessibility

We use semantic HTML, keyboard-operable controls, visible focus states, responsive layouts and reduced-motion support. If you encounter a barrier, email info@cannacon.org and include the page or task you were trying to complete.

Event accommodations

For mobility, seating, communication, sensory or other accommodation questions, contact info@cannacon.org as early as practical. We will coordinate with the applicable venue and event team.

Venue-specific information

Travel & venue resources ↗ include confirmed venue links. Venue accessibility details remain subject to each facility's current policies and services.

Alternative formats

Important booth, sponsorship, ticket and education information is provided as HTML on this site. If you need an alternative format for a PDF or other resource, contact us.
